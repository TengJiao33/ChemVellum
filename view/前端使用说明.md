# ChemVellum 前端使用说明

前端用于查看和校正 ChemVellum 在本地生成的阶段产物。

## 启动

在仓库根目录运行：

```bash
python view/serve_review_dashboard.py --review-root . --host 127.0.0.1 --port 8765
```

打开 `http://127.0.0.1:8765`。

## 页面

- `Library`：查看本地全文、MinerU 解析结果和元数据。
- `Discovery`：查看候选文献、筛选决定和 `selected_discovery_results.json`。
- `Matrix`：查看深读笔记、证据锚点、文献矩阵和大纲。
- `Blueprint`：查看章节论点、分配文献、比较轴和图表需求。
- `Sections`：查看分节草稿、段落证据链接和候选图。
- `Figures`：检查源图定位、复用依据、内容核验和重绘结果。
- `Draft`：查看合并稿、引用映射和待解决问题。
- `Final`：查看终稿、审校报告、DOCX 和发布状态。

页面顺序：

```text
Library -> Discovery -> Matrix -> Blueprint -> Sections -> Figures -> Draft -> Final
```

所有页面读取同一个 `review-projects/<project_id>`。修改结构化源文件后，重新运行对应阶段的生成器或验证器。
