# ChemVellum 前端使用说明

前端用于查看和校正 ChemVellum 在本地生成的项目产物。当前轻量工作流没有强制阶段机；项目的规范位置是：

```text
review-projects/<project_id>/
├─ project.json
├─ 00_discovery/
├─ manuscript.md
├─ assets/
├─ deliverables/
├─ notes/
└─ runs/<discovery_run_id>/discovery/
```

## 启动

在仓库根目录运行：

```bash
python view/serve_review_dashboard.py --review-root . --host 127.0.0.1 --port 8765
```

打开 `http://127.0.0.1:8765`。

## 页面

- `Library`：查看本地全文、MinerU 解析结果和元数据。
- `Discovery`：查看候选文献、筛选决定和 `selected_discovery_results.json`。
- `Matrix`、`Blueprint`、`Sections`：兼容查看旧项目留下的可选笔记；新项目不要求生成这些控制文件。
- `Figures`：优先读取 `assets/` 下的图源清单、资产清单和插图报告，同时兼容旧目录。
- `Draft`：读取并保存项目根目录的 `manuscript.md`；辅助笔记保存在 `notes/`。
- `Final`：优先读取 `deliverables/` 中的终稿和 DOCX，同时兼容旧目录。

所有页面读取同一个 `review-projects/<project_id>`。页面标签是浏览入口，不代表必须依次通过的门禁。再次运行 discovery 时，前一批检索会先归档到该项目的 `runs/`。
