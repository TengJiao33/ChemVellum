# 三篇综述模板的可用写作原则

本文档总结三篇有机化学综述的组织方式，供大纲设计、章节写作和图表选择使用：

```text
Allenation of Terminal Alkynes with Aldehydes and Ketones
New Approaches to the Synthesis of Metal Carbenes
Conquering Three-Carbon Axial Chirality of Allenes
```

结论来自论文正文、图表和 MinerU 结构化结果。写作时从中选择与当前主题匹配的组织原则。

## 1. 先选择一种主组织逻辑

### 研究发展线

`Allenation of Terminal Alkynes with Aldehydes and Ketones` 围绕 ATA/EATA 体系的发展展开：

```text
早期局限 -> 条件改进 -> 底物扩展 -> 不对称版本 -> 合成应用 -> 未解问题
```

这种结构适合范围集中的主题，尤其是一个反应体系或连续技术路线。章节的价值来自问题如何被逐步解决。

### 分类地图

`New Approaches to the Synthesis of Metal Carbenes` 先按卡宾来源分类，再在每类中按反应模式细分。它适合文献量大、读者需要快速定位方法家族的宽主题。

一级标题应保持同一分类轴，例如前体、底物、催化体系或反应类型。二级标题再承担更细的反应或应用分类。

### 合成入口

`Conquering Three-Carbon Axial Chirality of Allenes` 按手性联烯的合成来源组织，例如炔丙醇、末端炔、共轭烯炔、烯酮和消旋联烯。它适合拥有多个清楚方法入口的中等范围主题。

每类方法先说明反应逻辑，再比较代表方法的适用范围、选择性、条件、机制和限制。

### 选择标准

用中心问题决定结构：

| 中心问题 | 合适结构 |
|---|---|
| 一条技术路线如何演进 | 研究发展线 |
| 领域包含哪些方法家族 | 分类地图 |
| 同一目标可从哪些入口实现 | 合成入口 |
| 实际选择哪种方法 | 比较或决策结构 |

一篇文章可以局部使用其他组织方式，但一级标题需要一条稳定主轴。

## 2. 引言建立文章任务

引言完成四件事：

1. 说明研究对象的重要性。
2. 提出限制当前研究或应用的中心问题。
3. 界定综述覆盖的材料、方法、时期或证据类型。
4. 说明文章采用的组织逻辑。

范围说明应直接给出选择原则。例如：

```text
本文比较……条件下的三类方法，重点讨论……，并以……作为评价轴。
```

只有在排除项会改变读者理解时，才补充一句边界说明。

## 3. 章节围绕问题推进

论文是证据来源，不是默认的段落单位。一个段落通常围绕以下对象之一展开：

```text
方法类别
反应或应用问题
机制解释
范围和选择性变化
方法间比较
限制及其后续改进
```

一个成熟小节通常包含：

1. 本类方法的基本逻辑和它解决的问题。
2. 建立该方法的代表工作。
3. 改变适用范围或性能的后续进展。
4. 关键条件、范围、选择性和机制证据。
5. 当前边界及其对下一节的影响。

章节之间也应推进论证，例如从基础方法到高级版本、从消旋到不对称、从方法建立到复杂应用，或从共同限制到不同解决路线。

## 4. 每段给出一个可验证判断

段落先说结论，再用论文支撑。常见结构是：

```text
中心判断 -> 代表证据 -> 比较或解释 -> 适用边界 -> 对文章论点的意义
```

关键细节取决于读者需要，常见内容包括催化剂、配体、条件、产率、选择性、底物范围、失败底物和机制依据。只保留能够支持本段判断的细节。

比较需要明确共同评价轴，例如：

```text
底物类型
活化方式
操作条件
区域或立体选择性
官能团兼容性
规模和可操作性
证据强度
已知限制
```

## 5. 图表承担信息压缩

三篇模板都大量使用反应图式。高价值图表主要承担以下任务：

- 定义反应或方法类别。
- 展示代表条件和结构变化。
- 比较方法、底物范围或选择性。
- 解释机制及证据边界。
- 展示复杂分子应用。
- 概括分类和决策关系。

正文应引出图表、指出需要读取的信息，并解释其对论点的意义。一个图表可以支撑多个来源，但其中的结构、关系、数值和标签必须逐项核验。

选择顺序通常是：原创综述总览或比较表、能够代表一类方法的完整源图、经过核验的必要重绘。图表数量由信息任务决定。

## 6. 评价保持准确

评价强度应与证据一致：

```text
直接测量支持“显示”“达到”“观察到”
作者解释支持“提出”“归因于”“与……一致”
综述综合支持“在本研究集合中呈现”“共同表明”
```

“首次”“普遍”“成熟”“完全解决”等判断需要相应的覆盖范围和来源支持。局限直接写明具体对象和条件，例如“该体系尚未覆盖脂肪族底物”，比“仍有进一步研究空间”更有用。

## 7. 结论完成综合判断

结论回答：

1. 哪些能力已经建立。
2. 哪些方法差异会影响选择。
3. 哪些限制仍决定领域边界。
4. 哪些下一步最可能改变这些边界。

未来方向应从正文证据中推出，并说明它要解决的具体限制。

## 8. 用于 ChemVellum 的执行规则

- 大纲围绕一个主分类轴组织。
- 每节定义问题、主要判断、比较轴和核心证据。
- 每段绑定支持其判断的证据锚点。
- 代表方法写到足以比较和判断的深度。
- 图表绑定明确的阅读任务和证据来源。
- 章节末尾给出本节结论或边界，并推动下一节。
- 结论综合方法差异和未解问题，不复述目录。

这些原则的共同目标是让综述形成判断：读者既能看见领域结构，也能理解证据强弱、方法选择和仍然存在的边界。
