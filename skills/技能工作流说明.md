# ChemVellum 轻量工具说明

新克隆的本地库为空；使用过程中，PDF、MinerU 全文、元数据和项目产物都只在当前 checkout 内积累。每篇综述先创建 `CVR-0001-主题`、`CVR-0002-主题` 这样的独立目录；临时实验使用 `EXP-YYYYMMDD-001-主题`。当前科学解释维护在 `notes/synthesis_model.md`，面向读者的正文固定放在项目根目录的 `manuscript.md`，图和 Scheme 放在 `assets/`，最终 DOCX、PDF 与页面图放在 `deliverables/`。同一项目再次检索时，上一批 `00_discovery/` 会进入 `runs/<discovery_run_id>/discovery/`，不会静默覆盖。

共享的 `chem_papers/`、`mineru-outputs/` 和 `review-library/` 是逐步积累的本地论文库，不随某一篇综述复制。MinerU 每次真实解析另存一份 `mineru-outputs/runs/<run_id>.json`；论文注册号使用连续的 `P001`、`P002`，并在写 registry 时加锁避免并发重复。

`chemvellum-review-e2e` 接管从主题到最终页面检查的完整运行，负责选择下一步、调用其余 7 个组件 Skill 并在普通阶段之间继续执行；它不代替模型作科学判断，也不恢复旧式阶段机和门禁文件。`review-writing-tools` 只负责中心问题、化学判断、比较综合、结构与文字。模型直接阅读论文并维护一份 Markdown 正文。工作顺序由证据和写作需要共同决定，通常包括：

```text
明确主题与比较问题
形成并持续修正当前解释模型
广泛检索候选文献，再逐篇筛选
获取合法全文，必要时用 MinerU 解析
阅读能够建立、区分、修正或限制当前解释的全文
把同一解释展开为正文、比较表和有用图示
解释发生重要变化或出现高影响不确定性时返回检索
在阅读和写作过程中选择可合法复用的论文图示
生成稳定引用与参考文献
Markdown -> DOCX -> PDF
逐页查看真实渲染结果
```

检索采用“宽进、细筛”。首轮保留宽泛核心查询，再根据当前主题用短小的分面查询扩展对象、方法、条件、机制、测量、性质和应用等维度；一条很密的覆盖描述会拆成多个短查询，使排在后面的重要方面也能进入检索。默认会把全部规划分面送到外部来源；只有需要控制服务调用时才显式设置查询上限。首轮入库用于认识领域语言、主要路线、历史联系和比较问题。类别齐全只说明检索触及了这些方向；主要论点和比较得到直接全文支撑，才说明文献能够承载综合写作。阅读形成新问题后，在同一项目中继续定向检索。新结果大多重复已经理解的路线和证据时，文献集可以自然收束。

成熟主题先用相关综述理解领域语言和文献脉络，再沿参考文献追溯奠基方法，沿后续引用寻找改变范围或解释的代表性进展。全文阅读一旦建立、区分、修正或限制某项重要关系，就更新解释模型并同步调整正文结构；只是重复已经理解关系的论文只在独立支持、范围或代表性本身重要时进入论证。新的定向检索主要返回相同关系和证据时，解释可以自然收束。正文规模由中心解释包含的因果、条件、比较、竞争解释和适用边界决定，不由文献、字数、页数、图或表的数量决定。

检索结果和摘要用于筛选。研究对象、样品或底物、制备与运行条件、测量口径、比较基础、效应或选择性的来源以及机理证据等具体陈述，应回到当前本地全文核对。综述负责提供方向和历史，具体方法与比较由相应原始论文支撑。论文因为参与论证而被引用，不因为已经入库而被引用。写作时可保留几行检索或比较笔记。

`review-source-figure-tools` 同时生成 JSON 清单和按论文、原始页序排列的 HTML 缩略图浏览页，不按 caption 关键词推荐候选。模型在阅读和写作时浏览原图，并查看完整原页、图注、上下文、可读性和许可信息。正文、来源图、原创高层图解和比较表是同一解释模型的不同表达：具体化学结构、反应式和实验结果依靠核验过的来源图；因果、时序、尺度或决策关系适合图解；具有共同比较基础的信息适合表格；需要展开机理、证据强度和语境的内容使用叙述。已经为明确关系选中的合法来源图通常应进入正文；后来证据改变解释或发现图片不适用时直接放弃即可，不生成状态文件。图表均不设数量配额。

`review-writing-tools` 的快照、引用报告和 DOCX 结构报告提供编辑提示。脚本负责查找、复制、计数、编号、格式化和渲染；来源支持、图片许可、综合质量和页面观感由模型结合原文与实际页面判断。

最终交付前，修正实际引用来源的书目信息，生成 DOCX 后立即生成 PDF，并逐页打开页面图。只有真正打开查看过的页码才写入交接说明。
