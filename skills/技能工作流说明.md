# ChemVellum 轻量工具说明

模型直接阅读论文并维护一份 Markdown 正文。工作顺序由写作需要决定，通常包括：

```text
明确主题与比较问题
广泛检索候选文献，再逐篇筛选
获取合法全文，必要时用 MinerU 解析
阅读主要方法、关键差异、核心证据和代表性进展
写摘要、正文、比较表与综合图
阅读和写作产生新问题时返回检索
在阅读和写作过程中选择可合法复用的论文图示
生成稳定引用与参考文献
Markdown -> DOCX -> PDF
逐页查看真实渲染结果
```

检索采用“宽进、细筛”。首轮保留宽泛核心查询，再根据当前主题用短小的分面查询扩展对象、方法、条件、机制、测量、性质和应用等维度；一条很密的覆盖描述会拆成多个短查询，使排在后面的重要方面也能进入检索。默认会把全部规划分面送到外部来源；只有需要控制服务调用时才显式设置查询上限。首轮入库用于认识领域语言、主要路线、历史联系和比较问题。类别齐全只说明检索触及了这些方向；主要论点和比较得到直接全文支撑，才说明文献能够承载综合写作。阅读形成新问题后，在同一项目中继续定向检索。新结果大多重复已经理解的路线和证据时，文献集可以自然收束。

成熟主题先用相关综述理解领域语言和文献脉络，再沿参考文献追溯奠基方法，沿后续引用寻找改变范围或解释的代表性进展。写作在形成有用结构后开始，并把暴露出的缺失历史、争议、薄弱比较和间接证据带回检索。对于范围较宽的综合化学综述，约 40 篇真正相关且参与论证的引用来源可以作为尺度提示；明显低于这个量级时，再看一次主要路线、关键比较、历史联系和代表性进展是否偏薄。主题较窄时可以更少，范围更宽时也可以更多，最终数量仍由实际论证需要决定。

检索结果和摘要用于筛选。研究对象、样品或底物、制备与运行条件、测量口径、比较基础、效应或选择性的来源以及机理证据等具体陈述，应回到当前本地全文核对。综述负责提供方向和历史，具体方法与比较由相应原始论文支撑。论文因为参与论证而被引用，不因为已经入库而被引用。写作时可保留几行检索或比较笔记。

`review-source-figure-tools` 同时生成 JSON 清单和按论文、原始页序排列的 HTML 缩略图浏览页，不按 caption 关键词推荐候选。模型在阅读和写作时浏览原图，并查看完整原页、图注、上下文、可读性和许可信息。具体化学结构、反应式和实验结果依靠核验过的来源图；模型不重绘复杂化学结构或反应式。模型可以在能够准确表达时制作只承载跨论文关系的高层综合图。已经为明确读者问题选中的合法来源图通常应进入正文；后来发现不适用时直接放弃即可，不生成状态文件。表格用于呈现有共同比较基础的横向信息，例如同一口径下的方法、条件和结果；叙述用于展开机理、因果和研究语境。是否使用表格以及表格写什么，由当前论证需要决定。图表均不设数量配额。

`review-writing-tools` 的快照、引用报告和 DOCX 结构报告提供编辑提示。脚本负责查找、复制、计数、编号、格式化和渲染；来源支持、图片许可、综合质量和页面观感由模型结合原文与实际页面判断。

最终交付前，修正实际引用来源的书目信息，生成 DOCX 后立即生成 PDF，并逐页打开页面图。只有真正打开查看过的页码才写入交接说明。
